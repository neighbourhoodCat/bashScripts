# bashScripts

Just a pile of bash scripts I mess around with for fun. Nothing special, don't expect anything fancy.

## What's in here

- **fun.sh** – little menu to shutdown, reboot, check the OS release, flex your OS, or look at resource usage
- **serverMonitor.sh** – watches CPU and stuff on a loop (yeah, ChatGPT wrote most of it)
- **user_manager.sh** – menu for adding, deleting, locking and poking at Linux users so I don't have to remember the commands

## Running them

```bash
chmod +x fun.sh
./fun.sh
```

Same idea for the others. `user_manager.sh` will ask for sudo, so be careful with it.

## Notes

Made for learning and having fun. Might break, use at your own risk.
